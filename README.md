# homebrew-tap

Homebrew tap for [clavis](https://github.com/mutex-solutions/clavis).

## Install

```bash
brew install mutex-solutions/tap/clavis
```

Or tap first, then install:

```bash
brew tap mutex-solutions/tap
brew install clavis
```

Works on macOS (Apple Silicon + Intel) and Linux (Linuxbrew, amd64 + arm64).

Formulae here are regenerated from the release checksums by `scripts/gen-formula.sh`
in the clavis release workflow on each tagged release.

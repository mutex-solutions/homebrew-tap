# homebrew-tap

Homebrew tap for [clavis](https://github.com/dinhlongviolin1/clavis).

## Install

```bash
brew install dinhlongviolin1/tap/clavis
```

Or tap first, then install:

```bash
brew tap dinhlongviolin1/tap
brew install clavis
```

Works on macOS (Apple Silicon + Intel) and Linux (Linuxbrew, amd64 + arm64).

Formulae here are updated automatically by
[goreleaser](https://goreleaser.com) on each clavis release.
